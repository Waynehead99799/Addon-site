# Addon Web Solutions — Company Website

Next.js 14 (App Router) + TypeScript + Tailwind CSS port of the Claude Design handoff in `../website/`.

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3010.

## Structure

- `app/` — routes, layout, global CSS
- `components/` — ported sections (Nav, Hero, WaveMesh, Logos, Services, Stats, CaseStudies, Process, Testimonials, CTA, Footer)
